# Documenso

Open-source document signing: upload a PDF, place fields, send it out and get it back signed, on your own infrastructure.

## Features

- Signing workflows with multiple recipients, signing order and reminders
- Templates and direct links for recurring documents
- Teams, organisations and an API with webhooks
- Single sign-on through Emporium

## Perfect for

Teams that want a self-hosted DocuSign alternative and keep their contracts on their own servers.

Document signing needs a signing certificate (PKCS#12). Provide it at install in the "Signing certificate" section.
