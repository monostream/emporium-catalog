# Emporium Chart Manual

This manual was replaced by [CHART_AUTHOR_MANUAL.md](CHART_AUTHOR_MANUAL.md), which documents the `emporium.yaml` v1 model of Emporium v0.5.0 (inputs, integrations, components, profiles, secrets, lint) and ships worked examples.

The old `## @userSupplied` comment DSL, `.Emporium.UserSupplied` and the `.Emporium.Integrations.{DNS,OIDC,SMTP,Storage}` aliases no longer exist in v0.5. Start new charts from `charts/_template/`.
